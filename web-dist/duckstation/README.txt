=============================================================================
 DuckStation Web Build - Output Files
=============================================================================

This directory contains the WebAssembly build artifacts for DuckStation.
These files are generated by running: bash scripts/build-web.sh

Expected files after build:
----------------------------

duckstation-web.js          Main JavaScript module
duckstation-web.wasm        WebAssembly binary
duckstation-web.worker.js   Web Worker (if built with pthread support)
duckstation-web.data        Preloaded data files (if packaged)

File sizes (approximate):
-------------------------
.wasm file: 5-15 MB (depending on build type and features)
.js file:   200-500 KB
.data file: Variable (depends on packaged resources)

Loading these files:
--------------------
The index.html in the parent directory loads these files via ES6 module:

  import createDuckStationModule from './duckstation/duckstation-web.js';

Browser requirements:
---------------------
- WebAssembly support
- WebGL 2.0 or WebGL 1.0
- ES6 modules
- File API for ROM/BIOS upload
- (Optional) SharedArrayBuffer for threading

Note: These files must be served with proper COOP/COEP headers for
SharedArrayBuffer support. Use scripts/serve-web.sh for local development.
